# คำต้องห้าม (Forbidden Word)

เกมปาร์ตี้แนวเดียวกับที่เล่นในช่องเทพลีลา — ทุกคนถือ "คำต้องห้าม" ติดตัวคนละคำ
แต่มองไม่เห็นของตัวเอง หน้าที่คุณคือคุยหลอกให้คนอื่นเผลอพูดคำของเขาออกมา
ใครได้ยินก่อน กดจับได้เลย

เล่นผ่านเว็บ ไม่ต้องล็อกอิน ไม่ต้องติดตั้งอะไร

---

## กติกา

| เหตุการณ์ | คะแนน |
|---|---|
| จับผิดคนอื่นได้ | **+2** ต่อครั้ง |
| รอดจนจบรอบ | **+1** |
| โดนจับ | ออกจากรอบ ไม่ได้แต้ม |

สองอย่างบวกกันได้ — จับผิดคนนึงแล้วรอดจนจบรอบด้วย = 3 แต้ม

- **ใครก็จับผิดได้** ไม่ใช่แค่โฮสต์ — ได้ยินปุ๊บกดปั๊บ ใครกดก่อนได้แต้ม
  แต้มไปหาคนที่กดปุ่มชื่อคนนั้น ซึ่งปกติคือคนที่กำลังคุยกับเขาอยู่พอดี
- **คนที่โดนจับแล้ว จับซ้ำไม่ได้** คนอื่นมาแย่งแต้มจากเหยื่อเดียวกันไม่ได้
- คนที่ออกจากรอบแล้วจับผิดคนอื่นต่อไม่ได้ แต่ยังนั่งดูได้
- เหลือคนรอดคนเดียวเมื่อไหร่ รอบจบทันที ไม่ต้องรอหมดเวลา
- โฮสต์กด **ยกเลิกการจับผิดล่าสุด** ได้ภายใน 20 วินาที เผื่อกดพลาดหรือเถียงกันไม่จบ
- ระบบการันตีว่า**ไม่มีใครได้คำที่ตัวเองส่ง** และระหว่างรอบ คำของตัวเองจะไม่ถูกส่งมาถึงเบราว์เซอร์ตัวเองเลย
- **จบรอบแล้วเฉลยทั้งวง** ทุกคนได้เห็นคำที่ตัวเองถือมาทั้งรอบ พร้อมคำของคนอื่นและใครจับใครได้

### ข้อจำกัดเรื่องคำซ้ำ

ถ้ามีคนส่งคำเดียวกัน **เกินครึ่งวง** จะแจกไม่ได้จริงๆ (ทุกคนในกลุ่มนั้นต้องไปรับคำจากคนนอกกลุ่ม ซึ่งมีไม่พอ)
ระบบจะบอกตรงๆ ว่าต้องให้กี่คนเปลี่ยนคำ เช่น *"มีคนส่งคำว่า กิน ถึง 3 คน จาก 5 คน ... ให้เปลี่ยนคำอย่างน้อย 1 คน"*

## ฟีเจอร์

- **เน็ตหลุดไม่เสียคะแนน** — กลับเข้าลิงก์เดิมภายใน 90 วินาที ได้คะแนน คำ และสถานะเดิมคืนครบ
  (ผูกตัวตนด้วย `playerId` ใน localStorage ไม่ใช่ socket id จึงรอดทั้งการรีเฟรชและเน็ตกระตุก)
- **เฉลยท้ายรอบ** — การ์ดเฉลยโชว์คำของตัวเองตัวโต บอกว่ารอดหรือโดนใครจับ พร้อมคำของคนอื่นครบ
- **QR ชวนเพื่อน** — จิ้มที่ QR เพื่อขยายเต็มจอ แล้วยกจอให้ทั้งวงสแกนพร้อมกัน
  QR ยังขึ้นบนจอฉายด้วย คนดูสแกนจากทีวีเข้ามาเล่นได้เลย
- **จอฉายสำหรับสตรีม/ทีวี** — หน้าแยกที่โชว์คำของทุกคนตัวโตๆ พร้อมนาฬิกา
  เข้าได้เฉพาะคนที่มีคีย์ลับที่โฮสต์เท่านั้นเห็น
- **มือถือเป็นหลัก** — ปุ่มจับผิดอยู่แถบล่าง กดมือเดียวถึง ปุ่มทุกอันสูงอย่างน้อย 44px
- โฮสต์: ตั้งเวลา 1–15 นาที, พัก/เล่นต่อ, จบรอบ, ล้างคะแนน, เตะผู้เล่น, ยกโฮสต์ให้คนอื่น
- โฮสต์ที่เน็ตหลุดจะถูกย้ายให้คนที่ยังออนไลน์อัตโนมัติ ห้องไม่ค้าง

## โครงสร้าง

```
server/
  config.js    ค่าคงที่ทั้งระบบ
  assign.js    อัลกอริทึมแจกคำ (derangement) + เช็คว่าแจกได้ไหม
  rooms.js     ห้องและผู้เล่น ผูกด้วย playerId
  game.js      กติกาของรอบ: แจกคำ จับผิด คิดคะแนน
  state.js     ประกอบ state รายคน (กันคำตัวเองหลุด)
  server.js    ต่อสาย socket ทั้งสองเกม
  games/numbers/
    rules.js   กติกาทายเลข (ใช้ร่วมกับเบราว์เซอร์)
    state.js   ประกอบ state รายคน (กันเลขลับหลุด)
public/
  index.html   หน้าแรก สร้าง/เข้าห้อง
  game.html    หน้าเล่นเกม
  stream.html  จอฉาย
  numbers.html เกมทายเลข (ทั้งต่อหน้ากันและออนไลน์)
  store.js     จำตัวตนข้ามการรีเฟรช
  ui.js        helper ที่ใช้ร่วมกัน
  qr.js        วาด QR เป็น SVG (ใช้ qrcode-generator ที่เสิร์ฟจาก /vendor/)
  style.css    ธีมเวทีรายการวาไรตี้
```

**หมายเหตุ:** state เก็บใน memory ล้วน ไม่มีฐานข้อมูล — restart หรือ deploy ใหม่ ห้องที่ค้างอยู่จะหาย
และ scale เกิน 1 instance ไม่ได้ ถ้าต้องการเก็บถาวรหรือขยาย ต้องเพิ่ม Redis หรือ Postgres

# ทายเลข (Number Duel)

2 คน เลือกเลขลับคนละเลข **1–99** แล้วทายเลขของอีกฝ่ายให้เจอ
ทายผิดระบบบอก **สูงไป / ต่ำไป** พร้อมบีบช่วงที่เหลือให้อัตโนมัติ

เลขลับ 5 ทาย 6 → สูงไป → เหลือ **1–5**

## 2 แกน เลือกได้อิสระ

| | **ทายฝ่ายเดียวก่อน** | **ผลัดกันทาย** |
|---|---|---|
| **ต่อหน้ากัน** (เครื่องเดียว) | ทายจนครบโควตาแล้วสลับ | สลับตากันไปเรื่อยๆ |
| **ออนไลน์** (คนละเครื่อง) | เหมือนกัน | เหมือนกัน |

โหมดต่อหน้ากัน **ไม่ต้องสร้างห้อง ไม่ต่อ socket เลย** เปิดเว็บกดเล่นได้ทันที
มีหน้า "ส่งเครื่องให้ [ชื่อ]" คั่นทุกครั้งที่เปลี่ยนมือ กันแอบเห็น

## คะแนน

```
เจอเลข  →  +(โควตา − ครั้งที่ใช้ + 1) แต้ม
ไม่เจอ  →  0 แต้ม
```

โควตา 5: เจอครั้งแรก **+5** · ครั้งที่ 3 **+3** · ครั้งที่ 5 **+1**
สูตรเดียวทำให้ "ใครใช้ครั้งน้อยกว่าชนะ" เป็นจริงในตัว และสะสมข้ามเกมได้
โหมดผลัดกัน: ชนะ **+3** เสมอ **+1** ทั้งคู่

## รายละเอียดที่ตั้งใจทำ

- **ทายนอกช่วงหรือทายซ้ำ ไม่กินตา** เพราะเป็นการพิมพ์ผิด ไม่ใช่การตัดสินใจ
- **โหมดผลัดกันมีตาแก้ตัว** คนทายก่อนเจอ อีกฝ่ายได้ทายอีก 1 ตาให้เท่ากัน เจอด้วย = เสมอ
- **สลับคนเริ่มก่อนทุกเกม** จะได้ไม่มีใครได้เปรียบสะสม
- **เลขลับไม่ถูกส่งไปหาอีกฝ่ายเลย** จนกว่าจะจบเกม มีเทสต์ไล่ทุกฟิลด์ใน payload
- โควตา default 5 ปรับได้ 3–10 · หน้าเว็บเตือนให้ด้วยว่า 5 ครั้งครอบได้แค่ 32 จาก 99 เลข
  (ต้องใช้ 7 ครั้งถึงจะการันตีหาเจอด้วยการแบ่งครึ่ง)

## กติกาชุดเดียวใช้ทั้งสองฝั่ง

`server/games/numbers/rules.js` เขียนแบบ UMD — server `require` ได้ เบราว์เซอร์โหลดผ่าน
`<script src="/numbers-rules.js">` ได้ (server เสิร์ฟไฟล์เดียวกันตรงๆ)

โหมดต่อหน้ากันจึงรันกติกาชุดเดียวกับโหมดออนไลน์เป๊ะ ไม่มีทางเพี้ยนคนละทาง
และเขียนเทสต์ครั้งเดียวคุมได้ทั้งสองโหมด
