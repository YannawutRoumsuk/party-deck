# คำต้องห้าม (Forbidden Word)

เกมปาร์ตี้แนวเดียวกับที่เล่นในช่องเทพลีลา — ทุกคนถือ "คำต้องห้าม" ติดตัวคนละคำ
แต่มองไม่เห็นของตัวเอง หน้าที่คุณคือคุยหลอกให้คนอื่นเผลอพูดคำของเขาออกมา
ใครได้ยินก่อน กดจับได้เลย

เล่นผ่านเว็บ ไม่ต้องล็อกอิน ไม่ต้องติดตั้งอะไร

---

## กติกา

| เหตุการณ์ | คะแนน |
|---|---|
| จับผิดคนอื่นได้ | **+2** ต่อครั้ง |
| รอดจนจบรอบ | **+1** |
| โดนจับ | ออกจากรอบ ไม่ได้แต้ม |

สองอย่างบวกกันได้ — จับผิดคนนึงแล้วรอดจนจบรอบด้วย = 3 แต้ม

- **ใครก็จับผิดได้** ไม่ใช่แค่โฮสต์ — ได้ยินปุ๊บกดปั๊บ ใครกดก่อนได้แต้ม
  แต้มไปหาคนที่กดปุ่มชื่อคนนั้น ซึ่งปกติคือคนที่กำลังคุยกับเขาอยู่พอดี
- **คนที่โดนจับแล้ว จับซ้ำไม่ได้** คนอื่นมาแย่งแต้มจากเหยื่อเดียวกันไม่ได้
- คนที่ออกจากรอบแล้วจับผิดคนอื่นต่อไม่ได้ แต่ยังนั่งดูได้
- เหลือคนรอดคนเดียวเมื่อไหร่ รอบจบทันที ไม่ต้องรอหมดเวลา
- โฮสต์กด **ยกเลิกการจับผิดล่าสุด** ได้ภายใน 20 วินาที เผื่อกดพลาดหรือเถียงกันไม่จบ
- ระบบการันตีว่า**ไม่มีใครได้คำที่ตัวเองส่ง** และระหว่างรอบ คำของตัวเองจะไม่ถูกส่งมาถึงเบราว์เซอร์ตัวเองเลย
- **จบรอบแล้วเฉลยทั้งวง** ทุกคนได้เห็นคำที่ตัวเองถือมาทั้งรอบ พร้อมคำของคนอื่นและใครจับใครได้

### ข้อจำกัดเรื่องคำซ้ำ

ถ้ามีคนส่งคำเดียวกัน **เกินครึ่งวง** จะแจกไม่ได้จริงๆ (ทุกคนในกลุ่มนั้นต้องไปรับคำจากคนนอกกลุ่ม ซึ่งมีไม่พอ)
ระบบจะบอกตรงๆ ว่าต้องให้กี่คนเปลี่ยนคำ เช่น *"มีคนส่งคำว่า กิน ถึง 3 คน จาก 5 คน ... ให้เปลี่ยนคำอย่างน้อย 1 คน"*

## ฟีเจอร์

- **เน็ตหลุดไม่เสียคะแนน** — กลับเข้าลิงก์เดิมภายใน 90 วินาที ได้คะแนน คำ และสถานะเดิมคืนครบ
  (ผูกตัวตนด้วย `playerId` ใน localStorage ไม่ใช่ socket id จึงรอดทั้งการรีเฟรชและเน็ตกระตุก)
- **เฉลยท้ายรอบ** — การ์ดเฉลยโชว์คำของตัวเองตัวโต บอกว่ารอดหรือโดนใครจับ พร้อมคำของคนอื่นครบ
- **QR ชวนเพื่อน** — จิ้มที่ QR เพื่อขยายเต็มจอ แล้วยกจอให้ทั้งวงสแกนพร้อมกัน
  QR ยังขึ้นบนจอฉายด้วย คนดูสแกนจากทีวีเข้ามาเล่นได้เลย
- **จอฉายสำหรับสตรีม/ทีวี** — หน้าแยกที่โชว์คำของทุกคนตัวโตๆ พร้อมนาฬิกา
  เข้าได้เฉพาะคนที่มีคีย์ลับที่โฮสต์เท่านั้นเห็น
- **มือถือเป็นหลัก** — ปุ่มจับผิดอยู่แถบล่าง กดมือเดียวถึง ปุ่มทุกอันสูงอย่างน้อย 44px
- โฮสต์: ตั้งเวลา 1–15 นาที, พัก/เล่นต่อ, จบรอบ, ล้างคะแนน, เตะผู้เล่น, ยกโฮสต์ให้คนอื่น
- โฮสต์ที่เน็ตหลุดจะถูกย้ายให้คนที่ยังออนไลน์อัตโนมัติ ห้องไม่ค้าง

# ทายเลข (Number Duel)

2 คน เลือกเลขลับคนละเลข **1–99** แล้วทายเลขของอีกฝ่ายให้เจอ
ทายผิดระบบบอก **สูงไป / ต่ำไป** พร้อมบีบช่วงที่เหลือให้อัตโนมัติ

เลขลับ 5 ทาย 6 → สูงไป → เหลือ **1–5**

## 2 แกน เลือกได้อิสระ

| | **ทายฝ่ายเดียวก่อน** | **ผลัดกันทาย** |
|---|---|---|
| **ต่อหน้ากัน** (เครื่องเดียว) | ทายจนครบโควตาแล้วสลับ | สลับตากันไปเรื่อยๆ |
| **ออนไลน์** (คนละเครื่อง) | เหมือนกัน | เหมือนกัน |

โหมดต่อหน้ากัน **ไม่ต้องสร้างห้อง ไม่ต่อ socket เลย** เปิดเว็บกดเล่นได้ทันที
มีหน้า "ส่งเครื่องให้ [ชื่อ]" คั่นทุกครั้งที่เปลี่ยนมือ กันแอบเห็น

## คะแนน

```
เจอเลข  →  +(โควตา − ครั้งที่ใช้ + 1) แต้ม
ไม่เจอ  →  0 แต้ม
```

โควตา 5: เจอครั้งแรก **+5** · ครั้งที่ 3 **+3** · ครั้งที่ 5 **+1**
สูตรเดียวทำให้ "ใครใช้ครั้งน้อยกว่าชนะ" เป็นจริงในตัว และสะสมข้ามเกมได้
โหมดผลัดกัน: ชนะ **+3** เสมอ **+1** ทั้งคู่

## รายละเอียดที่ตั้งใจทำ

- **ทายนอกช่วงหรือทายซ้ำ ไม่กินตา** เพราะเป็นการพิมพ์ผิด ไม่ใช่การตัดสินใจ
- **โหมดผลัดกันมีตาแก้ตัว** คนทายก่อนเจอ อีกฝ่ายได้ทายอีก 1 ตาให้เท่ากัน เจอด้วย = เสมอ
- **สลับคนเริ่มก่อนทุกเกม** จะได้ไม่มีใครได้เปรียบสะสม
- **เลขลับไม่ถูกส่งไปหาอีกฝ่ายเลย** จนกว่าจะจบเกม มีเทสต์ไล่ทุกฟิลด์ใน payload
- โควตา default 5 ปรับได้ 3–10 · หน้าเว็บเตือนให้ด้วยว่า 5 ครั้งครอบได้แค่ 32 จาก 99 เลข
  (ต้องใช้ 7 ครั้งถึงจะการันตีหาเจอด้วยการแบ่งครึ่ง)

## กติกาชุดเดียวใช้ทั้งสองฝั่ง

`server/games/numbers/rules.js` เขียนแบบ UMD — server `require` ได้ เบราว์เซอร์โหลดผ่าน
`<script src="/numbers-rules.js">` ได้ (server เสิร์ฟไฟล์เดียวกันตรงๆ)

โหมดต่อหน้ากันจึงรันกติกาชุดเดียวกับโหมดออนไลน์เป๊ะ ไม่มีทางเพี้ยนคนละทาง
และเขียนเทสต์ครั้งเดียวคุมได้ทั้งสองโหมด

# 24 แต้ม

สุ่มเลข 4 ตัว เอามาบวกลบคูณหารให้ได้ 24 ใครคิดออกก่อนกดปุ่มแล้วพูดออกมา

## ระบบกันโกง

ปัญหาคลาสสิกของเกมนี้: A กดตอบ พูดถูกแล้ว แต่ B แกล้งไม่กดว่าถูก

ทางออกคือ **ให้ระบบเป็นกรรมการสูงสุด** เพราะมันคำนวณเฉลยทุกวิธีไว้แล้ว

```
B กดว่าถูก            -> A ได้แต้ม จบตา (ทางด่วน เร็ว ใช้ความเชื่อใจ)
B กดว่าผิด            -> A พิมพ์สูตร ระบบตัดสิน
B เงียบจนหมดเวลา       -> A พิมพ์สูตร ระบบตัดสิน
```

ถ้าพิมพ์แล้วสูตรถูกจริง **คนที่ปัดตกโดนหักแต้ม** การแกล้งกดว่าผิดจึงไม่มีทางได้กำไร
มีเทสต์เปรียบเทียบไว้ตรงๆ ว่าปัดตกของจริงขาดทุน ปัดตกของมั่วได้กำไร

ตัวคำนวณใช้เศษส่วนแท้ ไม่ใช่ทศนิยม เฉลยอย่าง `8/(3-8/3)` จึงหาเจอ

# ทายของ 20 คำถาม

คิดสิ่งของหรือสิ่งมีชีวิตไว้ให้อีกฝ่ายทาย ผลัดกันถามคำถามที่ตอบได้แค่ใช่/ไม่ใช่

- แต่ละตาเลือกได้ว่าจะ **ถาม** หรือ **ทาย** — ถามได้ไม่จำกัด ทายได้แค่ 3 ครั้ง
- ทั้งสองฝั่งมีเวลาคนละ 1 นาที หมดเวลาถือว่าฟาวล์และเสียตา
- มีคลังคำ 8 หมวด แยก "รู้จักทั่วไป" กับ "รู้จักน้อย" กว่า 200 คำ
- มีคำถามแนะนำให้ตอนคิดไม่ออก เลือกให้ตรงกลุ่มสัตว์หรือสิ่งของ
- ทายหมดสิทธิ์ทั้งคู่โดยไม่มีใครถูก = เสมอ

# คำต้องเชื่อม

ผลัดกันพิมพ์คำที่เชื่อมกับคำก่อนหน้าภายใน 10 วินาที

## ตัวตรวจคำซ้ำภาษาไทย

หัวใจของเกม: มี `ใบไม้` ไปแล้ว จะพูด `ต้นไม้` ไม่ได้ เพราะ `ไม้` ซ้ำ

ภาษาไทยเขียนติดกันไม่มีช่องว่าง จึงต้องตัดคำเองก่อนถึงจะเทียบได้:

1. **normalize** ลอกวรรณยุกต์ ทัณฑฆาต ไม้ไต่คู้ ช่องว่าง และอักขระล่องหนออก
   เลี่ยงด้วยการเขียน `ต้นไม` หรือ `ต้น ไม้` ก็ยังโดนจับ
2. **ตัดคำ** ด้วยพจนานุกรมคำมูล 260 คำ แบบ longest-match
3. **เทียบทุกพยางค์** กับทุกคำที่ออกไปแล้วในรอบนั้น

พจนานุกรมมี**คำมูลเท่านั้น** และมีตัวกรองอัตโนมัติคัดคำประสมออก
เพราะถ้าเก็บ `ต้นไม้` ไว้ longest-match จะกลืนทั้งคำ แล้วไม่มีวันเห็นว่ามันแชร์ `ไม้`
มีเทสต์คอยจับถ้าวันหลังมีคนเผลอใส่คำประสมเข้าไป

**ข้อจำกัดที่ยอมรับ:** พจนานุกรมไม่ได้ครบทั้งภาษา คำนอกพจนานุกรมจะตัดไม่ออก
แต่ยังมีการเทียบแบบ substring คอยรับอีกชั้น เพิ่มคำมูลใหม่ได้ที่ `LEXICON`

## ชาเลนจ์

ระบบตัดสิน "เชื่อมโยงกันจริงไหม" แทนคนไม่ได้ จึงใช้การโหวต

- ใครก็ได้ที่ยังอยู่กดชาเลนจ์คำล่าสุด แล้วเถียงกัน 3 นาที
- **คู่กรณีโหวตไม่ได้** เพราะมีส่วนได้เสีย
- ฝ่ายไม่เชื่อมโยงชนะ -> คนพูดตกรอบ คนชาเลนจ์ได้ 2 แต้ม และยังชาเลนจ์ได้อีก
- เสมอหรือแพ้ -> คนชาเลนจ์หมดสิทธิ์ทั้งรอบ (ต้องชนะให้ชัดถึงจะตีตกได้)

# สายลับ (Spyfall)

ทุกคนอยู่สถานที่เดียวกันและรู้ว่าที่ไหน ยกเว้นสายลับหนึ่งคนที่ไม่รู้อะไรเลย

- **38 สถานที่ 4 ชุด** สถานที่ละ 7 บทบาท เลือกได้ว่าจะใช้ชุดไหนบ้าง
- จับเวลา 8 นาทีตามต้นฉบับ (ปรับได้ 3–15)
- **สายลับหยุดเกมทายสถานที่ได้ทุกเมื่อ** ถูกได้ 4 แต้ม ผิดแพ้ทันที
- **ใครก็ได้เปิดโหวตกล่าวหา** ใช้เสียงข้างมาก (ต้นฉบับใช้เอกฉันท์ แต่ปรับให้เกมจบเร็วขึ้น)
- คะแนนตามต้นฉบับ: จับสายลับได้ทุกคนได้ 1 คนเปิดโหวตได้ 2 · สายลับรอดได้ 2 · ทายสถานที่ถูกได้ 4

รายชื่อสถานที่ทั้งหมดแสดงให้ทุกคนเห็น (จิ้มเพื่อขีดฆ่าช่วยจำ) แต่**สถานที่จริงไม่เคยถูกส่งไปหาสายลับ**
มีเทสต์ไล่ทุกฟิลด์ใน payload ยืนยัน

# หมาป่า (Werewolf)

กลางคืนหมาป่าออกล่า กลางวันชาวบ้านโหวตประหาร

**แอปเป็นคนคุมเกมแทนคน** ทุกคนจึงได้เล่นครบ ไม่ต้องมีใครเสียสละมานั่งคุมเกม

## บทบาท 14 แบบ จัดชุดเองได้

| ฝ่ายหมาป่า | ฝ่ายชาวบ้าน | ฝ่ายตัวเอง |
|---|---|---|
| หมาป่า · ลูกหมาป่า · ลูกสมุน · แม่มดดำ | ชาวบ้าน · ผู้พยากรณ์ · นักดูออร่า · หมอ · แม่มด · นักล่า · ผู้เฒ่า · พี่น้องร่วมสาบาน · คิวปิด | คนฟอกหนัง |

มี **4 เซ็ตแนะนำ** (มือใหม่ · คลาสสิก · ป่วนหนัก · สายหลอก) กดแล้วเล่นได้เลย
หรือปรับเองทีละบทบาทก็ได้ ระบบตรวจให้ว่าชุดที่จัดเล่นได้จริงไหม
เช่น หมาป่าเกินครึ่งวง หรือใส่ลูกสมุนโดยไม่มีหมาป่า จะเตือนพร้อมบอกเหตุผล

## จุดที่ตั้งใจทำ

- **ตายแล้วไม่เฉลยบทบาท** รู้กันตอนจบเกมเท่านั้น เกมยืดเยื้อและหมาป่าได้เปรียบขึ้น
- **หมาป่าเห็นหน้ากันเอง** ลูกสมุนเห็นหมาป่า แต่**หมาป่าไม่เห็นลูกสมุน**
- ผลการตรวจของผู้พยากรณ์ส่งถึงเจ้าตัวคนเดียว
- กลางคืนบอกแค่ว่า "ถึงคิวบทบาทไหน" ไม่บอกว่าใครเป็นคนนั้น (เหมือนคนคุมเกมประกาศ)
- คู่รักของคิวปิดตายตามกัน และชนะร่วมกันถ้าเหลือสองคนสุดท้าย
- นักล่าตายแล้วลากคนไปด้วยได้ ระบบหยุดรอให้เลือกก่อนไปต่อ
